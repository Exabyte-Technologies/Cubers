# Virtual cube touch controls

Tapping a colored sticker in the 2×2, 3×3 or 4×4 view now turns that sticker's face clockwise. The selected face follows the actual displayed orientation. Dragging rotates the view; the existing labelled move controls, inverse/wide turns, undo, hints and replay remain available in their existing flows. Read-only puzzle views continue to allow rotation without turns. The Pyraminx has its separate [tip/center controls and validation](PYRAMINX-CONTROLS.md).

The earlier cube view mapped every tap to `F`. It also repeatedly added the gesture's total displacement, making a drag's rotation depend on the number of touch events. The new gesture tracker applies only displacement differences. A drag that returns to its starting point, multiple touches, termination, invalid coordinates and repeated release callbacks cannot produce a tap turn. Picking refuses background, offscreen coordinates, zero-size layouts and black body surfaces. Layout coordinates are normalized independently of the GL pixel-buffer resolution.

The actual existing cube mesh construction is extracted to `cube-scene.ts` and shared with the tests. Picking transforms the ray into each mesh's local coordinate system and intersects its exact box or rectangle, then chooses the closest surface. Cube bodies participate in depth ordering so a black body surface cannot select a rear sticker. Direct local bounds also avoid misses at a sticker's internal triangle seam. This picker is specific to the generated boxes and rectangular stickers, rather than a general triangle-mesh picker. See [Three.js Ray methods](https://threejs.org/docs/pages/Ray.html).

Five regression groups cover all six faces on all three cube sizes after logical turns, rotated views and different layout sizes, body/background/invalid-coordinate refusal, event-sampling independence, and single-use/cancelled/multitouch/returning gestures. They exercise the real Three.js geometry and mathematical projection without a browser or native renderer. All **398 source checks**, mobile types and formatting pass. Web/iOS/Android JavaScript exports pass, and their native bundles contain the new instructions with the reserved service addresses. This is source and packaging verification; native touch, screen-reader and visual acceptance remain open.

The updated Linux web image records **193 source hashes** and **41 packaged files**. Non-root packaging and the existing three-host production proxy configuration pass inspection.
